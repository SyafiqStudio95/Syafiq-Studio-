# Skrip bacaan voice over: Penghantaran Pelajar Batch ke-12 MUST

Sasaran: semua 6 bahagian dibaca dalam **±85 saat**, supaya ada 4-5 saat di hujung untuk logo.
Masa di sebelah setiap bahagian ialah masa yang digunakan dalam video sekarang.
`/` = jeda pendek (tarik nafas) · `//` = jeda panjang antara bahagian

## 1. Pembukaan (0:00 – 0:14) · ±13 saat · nada tenang, perlahan
Setiap perjalanan besar / bermula dengan sebuah langkah. /
Hari ini, / satu lagi lembaran perjuangan ilmu bakal tercipta, /
apabila seramai dua puluh orang pelajar Batch ke-12 MUST / diraikan dalam majlis penghantaran / ke Isparta, Turki. //

## 2. Pengenalan pelajar (0:14 – 0:28) · ±13 saat
Terdiri daripada empat belas orang pelajar lelaki, / dan enam orang pelajar perempuan, /
mereka bakal membawa satu misi dan harapan besar, /
untuk menduduki Peperiksaan Diploma Hafazan, / di bawah Kementerian Agama Islam Turki. //

## 3. Barisan pengurusan (0:28 – 0:44) · ±16 saat · sebut nama dengan jelas
Turut mengiringi rombongan kali ini / ialah Puan Hajah Siti Norbaya binti Abd Rahman, / Ketua Pengurus Operasi MUST, /
serta Ustaz Wan Abdul Baith Izzuddin bin Wan Mustafa, / Pengetua, /
sebagai tanda sokongan dan komitmen berterusan / dalam melahirkan generasi huffaz berwibawa. //

## 4. Detik penuh emosi (0:44 – 1:01) · ±16 saat · lebih lembut, beremosi
Lebih bermakna, / detik penuh bersejarah ini / turut disaksikan oleh ahli keluarga serta alumni / yang hadir memberikan sokongan dan doa. /
Setiap pelukan, / senyuman / dan titipan kata / menjadi kekuatan buat anak-anak ini / melangkah ke bumi asing / demi sebuah cita-cita. //

## 5. Bacaan doa (1:01 – 1:13) · ±12 saat
Majlis diteruskan dengan bacaan doa / yang dipimpin oleh Ustaz Asem Abd Karim, /
memohon agar perjalanan dipermudahkan, / segala urusan diberkati, / dan kejayaan mengiringi setiap langkah mereka. //

## 6. Penutup (1:13 – 1:27) · ±13 saat · naikkan semangat
Selamat berjuang, Batch 12! /
Pergilah membawa al-Quran di hati, / ilmu sebagai bekalan, / dan doa keluarga sebagai kekuatan. /
Semoga pulang nanti / dengan kejayaan yang membanggakan. //
MUST. / Melahirkan generasi huffaz berwibawa.

## Tip rakaman
- Rakam di bilik senyap (tutup kipas/aircond). Langsir atau almari baju membantu kurangkan gema.
- Telefon 15-20 cm dari mulut, sedikit ke tepi supaya bunyi "p" dan "b" tidak meletup. Guna app Voice Memos / Perakam Suara.
- Boleh rakam **satu fail untuk semua**, atau **satu fail untuk setiap bahagian** (lebih mudah ulang kalau tersilap).
  Kalau tersilap, berhenti sekejap dan ulang ayat itu. Saya akan buang yang salah.
- Diamkan 2 saat sebelum mula bercakap (untuk buang bunyi bilik).
- Muat naik ke folder Google Drive yang sama (format m4a / mp3 / wav). Saya akan selaraskan kapsyen, kad dan shot dengan bacaan anda.
- Kalau bacaan lebih panjang daripada 1:30, saya boleh laraskan sedikit (rapatkan jeda), atau ringkaskan ayat. Beritahu saya mana yang anda pilih.
